# Security

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/jasonsdevspace/design-kit/security/advisories/new)
rather than in a public issue.

## Supported versions

The package is not published, so fixes land on main.

## Dependencies and licenses

The package has no dependencies. Everything the repository installs is a tool for checking the
code, and none of it ships. Among them, a lint plugin is under the GNU Lesser General Public
License, and a CSS parser the test runner depends on is under the Mozilla Public License. Both are
accepted for tools that run only in development. A moderate advisory in a pattern matcher that the
lint tools depend on waits for those tools to take its fix.
