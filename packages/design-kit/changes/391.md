A row's detail wraps pretty where the browser can, so its last line rarely holds one word alone.

- **Sheets.** `dk-row-detail` sets `text-wrap-style: pretty`, the style alone, so a row a page keeps
  from wrapping stays on its line, and a browser that cannot wrap pretty drops the rule.
- **Tests.** A browser test finds a long detail in a tile ending on more than one word where the
  browser wraps pretty.
