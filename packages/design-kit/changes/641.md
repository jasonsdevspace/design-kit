A page that imports a function of the controls bundles nothing of the theme script, and the controls
carry budgets for what a page that imports one function pays.

- **Controls.** The theme module writes its two themes as plain strings, so the theme script's text
  calls nothing as the module loads and a bundler drops it from a page that imports the controls or
  the theme's names alone. The theme script is unchanged, and so is its hash.
- **Docs.** Record 13 gives budgets for the controls imported bare, `attachTable` alone and
  `attachForm` alone, with their first figures, measures every budget of the controls from the
  package as npm ships it with one median, and lets a release that leaves more than two medians of
  room under a budget lower it by the same rule.
- **Tests.** The budget tests measure the controls from the package laid out as npm ships it, hold
  the controls imported bare, `attachTable` alone and `attachForm` alone to budgets of their own,
  and find nothing of the theme script in a bundle of the theme names the controls import. A unit
  test finds each theme word written in quotes as JSON writes it.
