Focus and a refusal a React page asks for after a save wait for React to draw the save's change.

- **React.** The function `useFocusAfterDraw` returns, and the refusal `useFormRefusal` returns, each make their request once the render they were asked in commits, so a page that sets its state after an await, such as a save to the browser's storage, and then asks for focus or a refusal finds the control drawn and on, or the field in error, though React draws that state in a task of its own and a frame can come before it. Where focus was as the request was asked is still what it reads as where it came from.
- **Docs.** The comments of both hooks say they can be called after an await in a handler.
- **Tests.** Browser tests press a button that awaits a task, turns a control on and asks for focus on it, and refuse a form whose error is set after an await, each with frames run before React draws, and find focus on the control and on the field with the count said.
