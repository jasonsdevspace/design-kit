The repository takes its lint, format and TypeScript settings from the shared config package, which holds the kit's code to stricter TypeScript checks.

- **Controls.** The helper that reads which options an attach was given returns nothing in plain words where no key of its own has a value, as the stricter check that every path returns asks, with no change to what any control does.
- **Tests.** The browser tests read computed style properties outside TypeScript's own list by name in brackets, as the stricter check on index signatures asks.
