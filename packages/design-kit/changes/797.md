The repository takes its lint, format and TypeScript settings from the shared config package, which holds the kit's code to stricter TypeScript checks.

- **Controls.** The helper that reads which options an attach was given returns nothing in plain words where no key of its own has a value, as the stricter check that every path returns asks, with no change to what any control does.
- **Tests.** The browser tests name each key read through an index signature in brackets, as the stricter check on index signatures asks: data attributes, the record of controls a page draws by name and of the form errors it shows, and computed style properties outside TypeScript's own list. The package's install smoke test stays outside the lint, and so outside the rule that a disable comment says why, since it imports the package's build, which does not exist yet when the lint runs.
