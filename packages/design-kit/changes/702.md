A dialog and a panel the page attaches inside a frame of its own origin read focus, and hear the
frame's presses and keys, in the frame's document.

- **Controls.** `attachDialog` on a dialog inside a frame of the page's own origin finds its opener
  and reads focus in that frame's document, so as it closes focus goes back to the control in the
  frame that opened it, where it went to the frame or nowhere. `attachPanel` on a button inside such
  a frame listens in the frame's document, so the button opens and closes its panel, and focus goes
  back to it as the panel closes, where a press there did nothing. A button the page made and moved
  into the frame works alike. Each stays in the document it was attached in, so a page that moves
  one into another takes it down and attaches it again. A dialog and a panel on the page work as
  they did.
- **Docs.** The reference's dialog and panel sections say each works inside a frame the page drives,
  and record 19 has an amendment for it.
- **Tests.** Browser tests attach a dialog and a panel inside a frame from the page and find focus
  handed back to the control in the frame as each closes, one the page made and moved there among
  them, the frame's listeners coming off at takedown, and nothing added to the page's document.
