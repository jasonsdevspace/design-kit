A page can draw an empty list, table or rows that says what is missing and offers the next step.

- **Sheets.** `dk-empty` draws a message in the muted text at the body size and an action under it, `--dk-space-3` apart and with `--dk-space-3` above and below, with no ground, no edge and no room at its sides, so its words start where a row's title would and it never reads as a callout.
- **Docs.** The reference's Rows section has an empty list, drawn from a new example of an empty list of players with a first step, and a React part of saved games, written from a file in the examples module, whose search that matches nothing draws the empty state, says so on the status line once the visitor stops typing, and sends focus back to the search when it is cleared. The action is a plain button, since the accent action is the dock's, and the empty state is not live.
- **Tests.** Browser tests in Chromium and WebKit find no ground, edge or side room, the words at a row title's start, muted at the body size, a plain button a step under them, the empty state whole on a 320px phone at twice the text size and under wider spacing, the search that matches nothing drawing it and saying so, clearing it bringing the list back with focus on the search, and no audit findings in both themes, in forced colors and with the empty state drawn.
