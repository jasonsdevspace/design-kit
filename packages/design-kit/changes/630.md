`useArrivalFocus` and a late `useFocusAfterDraw` request work from inside a shadow root.

- **React.** `useArrivalFocus` reads where focus was through `activeOf()`, as `focusOnArrival` and
  `useFocusAfterDraw` do, so a view whose key changes on a press of a button inside a shadow root
  takes focus on its heading. Before, it read the root's host, and the request was dropped as
  though the visitor had moved. A request `useFocusAfterDraw` makes late, once its component has
  gone, finds an id, its target's or a fallback's, in the root where focus was when it was asked,
  as `moveFocus` does, so one inside a shadow root is found in sight and lands where the page
  passes `from` in that root or focus is still in it.
- **Docs.** The reference's section on moving focus says a late request finds an id in the root
  where focus was as it was asked.
- **Tests.** Browser tests in Chromium, WebKit and Firefox press a button inside a shadow root that
  changes a view's key and find focus on the view's heading, and ask late, from a component since
  gone, for an id inside a shadow root and find focus there.
