- **Upgrading.** A `dk-note` is drawn at the normal weight wherever it sits, so a note inside a heading, a strong title or a button no longer takes their weight, and a page that set a note inside a label back to the normal weight can take its own rule away.
- **Sheets.** `dk-note` shares the field's mark's rule for the muted text at the normal weight, so a note inside a field's label reads as a note rather than at the label's medium weight, with no page CSS.
- **Docs.** The reference's split row, note and numeral section says a note is any that is not a field's hint or error, such as a word beside a label's, and that it is at the normal weight.
- **Tests.** Browser tests find a note inside a field's label at the normal weight and muted while the label keeps its medium weight, with no audit findings, in both themes.
