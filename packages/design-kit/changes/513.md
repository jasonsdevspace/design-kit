A note beside a label's words is drawn at the normal weight.

- **Sheets.** `dk-note` sets the normal weight, so a note inside a field's label reads as a note rather than at the label's medium weight, with no page CSS, as a field's mark already does.
- **Docs.** The reference's split row, note and numeral section says a note is at the normal weight.
- **Tests.** A browser test finds a note inside a field's label at the normal weight while the label keeps its own.
