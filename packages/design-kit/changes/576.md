A focus request asked from inside an open dialog lands where the page asked as the dialog closes.

- **Docs.** The reference's dialog and record 23 say that a `moveFocus` request asked from the press
  that closes a dialog sends focus there rather than to the opener, whether the dialog is closed,
  taken from the page or taken down in that task.
- **Tests.** Browser tests ask `moveFocus` from inside an open dialog, then close it or take it from
  the page and take it down in the same task, and find focus on the element asked for in Chromium,
  WebKit and Firefox.
