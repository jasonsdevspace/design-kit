A page can take down the stepper, a table's frame, a group the arrow keys move through, a busy button, progress, the dialog and a focus request by aborting a `signal`, under the teardown contract of record 22.

- **Controls.** `attachStepper`, `attachTable`, `attachRoving`, `attachBusy`, `attachProgress` and `attachDialog` take an `AbortSignal` as `signal`, and aborting it does what the function they return does. `attachTable` takes its options as a new second argument. A signal already aborted attaches nothing and leaves a piece already attached with the options it had. The dialog, whose attach returns what opens it, is taken down by its signal alone: an open dialog closes with focus handed back to what opened it, its listeners and the `closedby` it set come off, and its open function does nothing. A busy wait still running is cleared, so its words are never said. `moveFocus` takes a `signal` that calls off a request not yet landed, as the function it returns does, and a request that lands lets go of the signal. A request asked as its component unmounts still lands when it is given no signal that unmount aborts. Each takes itself down through the internal helper in place of its own guard against a second detach.
- **Docs.** The reference names `signal` on each, and says how the dialog is taken down and how a focus request asked at unmount still lands. Record 22 lists them among the attaches that keep the contract.
- **Tests.** Browser tests in Chromium, WebKit and Firefox attach each with a signal already aborted and find nothing attached and a repeat attach's options not taken, abort a signal and find each taken down and an open dialog closed with focus back on its opener, find a detach, an open, a press, a step of progress and the arrow keys doing nothing after the teardown, find a busy wait and a pending focus request called off by an abort, find an old detach called twice and its signal aborted leave a newer attach alone, and find a later attach's signal unheard. In Chromium they count the listeners on the pieces' own elements and find every one off after an abort, and find a focus request that landed holds nothing on the page's signal.
