A toast sends focus back to the control the visitor came into it from.

- **Controls.** `attachToast` hands focus back to the control focus came into the toast from, so a
  keyboard user who moved on from where they were as the message came lands where they left off.
  Where focus came into the toast from nowhere, it still goes back to where it was as the message
  came.
- **Docs.** The reference, the toast's doc comment and record 23 say where a toast sends focus.
- **Tests.** Browser tests move from a field to a second control and into a shown toast, dismiss it
  by its action and by Escape and find focus on the second control, and find focus that came into
  the toast from nowhere sent back to where it was as the message came.
