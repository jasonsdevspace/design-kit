A toast sends focus back to the control the visitor came into it from.

- **Controls.** `attachToast` hands focus to the first of these that takes it: the control focus
  last came into the toast from, then the control that had focus as the latest message came, then
  the body of the app's frame or the page's main content. A keyboard user who moved on from where
  they were as the message came lands where they left off. Focus that last came into the toast from
  nowhere passes over the first, and a control inside an open shadow root counts as itself rather
  than as its host.
- **Docs.** The reference, the toast's doc comment and record 23 give that order.
- **Tests.** Browser tests move from a field to a second control and into a shown toast, dismiss it
  by its action and by Escape and find focus on the second control, and find focus sent back to
  where it was as the message came where that control is disabled first, where focus last came in
  from nowhere and where it only ever came in from nowhere. Another finds focus sent back to a
  control inside an open shadow root. The toast's browser tests run in Firefox too.
