How the kit's React hooks wrap its attach functions is settled in a new decision record.

- **Docs.** Record 20 says each hook attaches a function from `./controls` through a callback ref, keeps only its handle, sets its options again only when one changes and returns what the function returns, amending records 5, 13 and 14, and the reference's React section names the rule.
- **Tests.** The lint holds `react.tsx` to importing no effect from React, so the markup components stay free of effects and hooks go in their own module.
