  focused.

  each write kept so the same words said again are kept again, and the one swap of the kit's sheets
  for the same sheets as a browser without `:has()` reads them, which fails where the swap leaves a
  rule naming `:has()` in the kit's part. Every spec and page that heard a line or swapped the sheets
  uses them. A stepper's tests of a takedown with a button focused have a spec of their own, run in
  Chromium, WebKit and Firefox. The tests that lined a read-only stepper's figures up with a field's
  words measure where the words start from the boxes and the alignment rather than from the first
  dark pixel of each face, so a font a runner swaps in moves nothing, and a value drawn 2px off its
  place fails them.
