A detach called again does nothing, so it never undoes a newer attach of the same element.

- **Controls.** The detaches of the theme switch, the copy button, the stepper, the table, a group the arrow keys move through, a busy button and progress do their work once and nothing when called again. Called late, after the page attached the same element again, one of them used to take the newer attach's entry and, for the switch, the copy button and the stepper, hide the controls it had shown, so the next attach built a second instance with every listener twice. The panel's detach already kept to its own attach.
- **Tests.** A browser test attaches each of them, detaches it, attaches it again and calls the first detach again, and finds the newer attach still in place, its switch and copy button shown, its stepper stepping and its busy button marked off as it goes busy.
