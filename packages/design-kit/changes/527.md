The copy button's options type is exported beside every other attach function's.

- **Controls.** `CopyOptions`, what `attachCopyButton` takes, is exported from `./controls`, so a TypeScript page can build a copy button's options apart from the call, as it can a stepper's or a form's.
- **Docs.** The reference's list of what `./controls` exports names `CopyOptions`.
- **Tests.** The type smoke test, compiled against the packed package, imports `CopyOptions` and types a copy button's options with it.
