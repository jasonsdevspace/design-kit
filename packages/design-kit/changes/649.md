F8 reaches a shown toast's action in one keystroke from anywhere on the page, and sends focus back
where it came from.

- **Controls.** `attachToast` moves focus to a shown action on F8 pressed with no modifier and not
  held, and on F8 pressed in the toast sends focus back where it came from by the walk a dismiss
  hands it back by, with the toast still shown. Enter, Space and Escape on the action do what they
  did, and focus goes back to the control F8 was pressed on. Focus still never moves as a message
  shows. The action carries `aria-keyshortcuts="F8"` while it is shown. The toast listens for the
  key on the document only while a message with an action is shown, takes the listener off as the
  toast hides, as a message with no action replaces it or as it is taken down, and keeps the key's
  default wherever it moves no focus, for an F8 that converts text in an input method too. With
  focus in one of two toasts, that toast hears the key. A page's own F8 handler on an element below
  the document runs first and wins where it prevents the default, while one on the window or the
  document may run after the toast's, so it checks `defaultPrevented`. A page needs nothing to get F8, so Game Table Tally's Undo
  takes it as it is.
- **Docs.** Record 29 gives the key, the options turned down and the spoken hint that waits for a
  walk with NVDA and VoiceOver. The reference names the key, record 19 names the walk back, and
  record 13 gives the controls' size with the key.
- **Tests.** Browser tests in Chromium, WebKit and Firefox, on a page of many controls, find F8
  moving focus to the action, Enter running it and Escape dismissing the toast with focus back
  where F8 was pressed, F8 in the toast sending focus back with the toast still shown, F8 with no
  toast, with no action, with a modifier, as a repeat or after a dismiss moving nothing and keeping
  its default, as does an F8 that converts text in an input method, F8 in the toast going on down
  the walk where its control is gone, following a frame of the page's own origin and heard by the
  toast that holds focus, and `aria-keyshortcuts` on the action while shown and not after. The leak tests count
  the document listener only while a message with an action is shown, and the teardown table's
  toast shows one, so its takedown is found to take the listener off.
