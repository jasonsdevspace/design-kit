A status line attached again returns the function it returned first, as every attach function does.

- **Controls.** `attachStatus` keeps the function it returns for each line, so attaching a line
  again returns the same one, and its comment and decision 0015 agree that a screen keeps a line of
  its own, which a copy button handed it too shares one timer with.
- **Tests.** A unit test attaches one line twice and gets the same function, and another line a
  different one.
