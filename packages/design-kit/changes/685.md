The browser tests in Firefox run with the browser's list of words sent from forms turned off.

- **Tests.** Firefox kept the words each test sent from a form for every later test in the same
  browser, and listed them under a field filled with the same words again. A press on the page made
  as the list opened never reached it, so a checked form's stepper test that filled a name and then
  pressed Send at times found the form never sent and waited for a refusal that never came. The
  Firefox project turns that list off, and a browser test finds a field offered none of the words a
  test before it sent.
