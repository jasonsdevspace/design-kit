A refused form moves focus to its first error and says once what needs attention.

- **Controls.** `attachForm(form, { status, say, summary })` returns what refuses a submit once the page has drawn its errors: a frame later focus moves to the summary, the first field in error that can take focus, or in a set its checked radio or first control, and one message is said, nothing where focus moves to the summary, how many fields need attention where focus moves to a field, and the error's own words, with the count where more are wrong, where the field already had focus. A set counts once, a refusal with nothing wrong leaves focus where it is, and each refusal returns what calls it off. A focus target can be a function, read as focus moves.
- **React.** `useFormRefusal(options)` returns a ref for the form and what refuses it, speaking on the screen's `StatusProvider`, calling a refusal off on unmount, and throwing with no provider or `say`.
- **Docs.** The reference's Fields section shows the refused form with the helper.
- **Tests.** Browser tests refuse with focus elsewhere and hear the count, refuse with focus on the field and hear its error, with the count where more are wrong, pass over a disabled field, count a set of checkboxes once, leave focus where it is with nothing wrong, focus a radio set's checked radio and a named summary with nothing said over it, and refuse a React form through the screen's status line.
