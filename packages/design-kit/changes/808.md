The saved games search's browser tests hold its words to typing that stopped on a stopped clock, so a slow browser never fails them.

- **Docs.** The reference's saved games example names its search's wait for typing to stop, which its tests read.
- **Tests.** The tests that type a search into the saved games type on a stopped clock and run it on purpose, so a pause between keys on a loaded machine never reads as typing that stopped. The test of a search that matches nothing finds a pause shorter than the wait saying nothing, since each key starts the wait again, and finds the line still empty a moment before the words are due after the last key.
