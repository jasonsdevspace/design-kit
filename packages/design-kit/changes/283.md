A link in running text is held to its underline by a test.

- **Docs.** The reference says a link in running text keeps the browser's underline, since the
  accent stands too close to the text to mark it by color alone, and that each piece that is a link
  takes it off in its own class.
- **Tests.** Browser tests find a link underlined at rest in a paragraph, a list, a callout, a panel
  and a dialog, in both themes and in forced colors, and a button, a pill, a tab and a row that are
  links with no underline.
