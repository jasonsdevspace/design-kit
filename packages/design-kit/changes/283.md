A link in running text is held to its underline by a test.

- **Docs.** The reference says a link in running text keeps the browser's underline, since the
  accent stands too close to the text to mark it by color alone and a footer's link takes the
  footer's muted color, that a text button puts it back, and that each other piece that is a link
  takes it off in its own class.
- **Tests.** Browser tests find a link underlined at rest, in a color that shows, in every place it
  sits in running text from the strip to the footer, a dialog, a table and a toast among them, in
  both themes and in forced colors, and each piece that is a link with no underline.
