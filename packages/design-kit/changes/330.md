Each browser test holds what its title says, the rows and tiles run in WebKit, and forced colors and
the keyboard's ring come from shared helpers.

- **Tests.** A screen's status line is stepped on a stand-in clock and must empty between two same
  messages. A field's button must sit on its control's row on a wide screen at the browser's text
  size. A table frame's shade, a sheet's rise, an icon's doubled stroke and the site's rule mark,
  chosen things and end shade are read as drawn or as the browser fires them, so each fails when
  what it names is gone. The chosen things' forced colors tests cover the collapsed theme switch and
  a tab bar's current place. The rows and tiles run in WebKit too. A link's underline is measured at
  3 to 1 against the ground it sits on, a translucent color is weighed over its ground in every
  contrast, a ground or shadow drawn on a token is compared with the token, every loop over found
  elements counts them first, and CI fails a test that passes only on its retry.
