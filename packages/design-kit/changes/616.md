The reference and record 20 say that a form React still draws refuses through `useFormRefusal`.

- **Upgrading.** A React page that attaches `attachForm` to a form it still draws, as from an
  effect, moves to `useFormRefusal` and draws each error from its state. A page that renders the
  React components to static HTML and attaches the form from plain script keeps `attachForm`.
- **Docs.** The reference's section on a refused form says `attachForm` draws errors only in markup
  nothing will draw again, a page written by hand or the React components rendered to static HTML
  and attached from plain script, that a form React still draws refuses through `useFormRefusal`,
  and that `attachForm` drawing its own errors in a form React still draws is not supported. Record
  20 and the decisions index say why each node and attribute of a field keeps one owner, and why a
  mark on every React field and an observer that repairs React's markup were turned down.
- **Tests.** A browser test in Chromium, WebKit and Firefox refuses a field through
  `useFormRefusal`, draws its error again with new words, plain and with an address, while the
  refusal stands, and finds no exception, one error with the field's id, shown, described and
  marked, focus on the field and the refusal said once on the status line. The form tests run in
  Firefox as well.
