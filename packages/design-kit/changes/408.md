A panel stays as it is when an off button is pressed or a second button is attached.

- **Controls.** A press of an attached button with `aria-disabled="true"` leaves its panel alone,
  as a stepper's off button does, and focus never goes back to an off button as a panel closes. A
  button attached for a panel that an earlier button started, one drawn again among them, marks
  itself as the panel is and leaves it alone, so a button drawn later never closes a panel the
  visitor opened, nor takes the place of the button that opened it. The first button for a panel
  still starts it as its markup says.
- **Docs.** The controls' budget is 7.5 KB, set again by the budgets' rule with these fixes in
  place. The reference's corner Close and the controls' doc comment say both. The reference's
  frame and band insets name `--dk-app-side`, and its tab bar draws its icons as kit icons, with
  `dk-icon`, so they take the kit's stroke.
- **Tests.** Browser tests press an off button by key and pointer, with the panel closed and open,
  and find it unchanged, hand focus past an off button as the panel closes, and attach a second
  button, or a button drawn again, to an open panel and find it open, the button expanded and focus
  going back to the button that opened it.
