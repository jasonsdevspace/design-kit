A form submitted inside an open shadow root counts as a press, so a view its submit brings for the first time focuses its heading.

- **Controls.** The kit hears a submit inside each open shadow root that focus enters or a key or a click passes through, an open root inside a closed one the kit hears among them, and one around what has focus as the kit loads, by a listener on the root itself, since a submit never leaves the root its form is in. Before, the page never heard it, so the view a submit inside a widget's open root brought took no focus. A field that sends its own form once a phone fills in a code counts too. Only a form a script submits inside a root focus never entered still counts for nothing.
- **Docs.** Record 19 says so and names the case it leaves, and the reference says so in its section on focus on arrival.
- **Tests.** Browser tests submit a form inside an open shadow root in Chromium, Firefox and WebKit, by Enter in its field, by Enter, Space and a pointer on its submit button, by a script after a click in the root or after focus entered an open root inside a closed one, by its own field once a code is filled in, and where its field had focus before the kit loaded, and find the view the submit draws for the first time taking focus, and a form a script submits before any input or focus there taking none.
