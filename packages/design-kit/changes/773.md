A form submitted inside an open shadow root counts as a press, so a view its submit brings for the first time focuses its heading.

- **Controls.** The kit hears a submit inside each open shadow root a key or a click on the page passes through, by a listener on the root itself, since a submit never leaves the root its form is in. Before, the page never heard it, so the view a submit inside a widget's open root brought took no focus. A form a script submits there with no input before it still counts for nothing.
- **Docs.** Record 19 says so and names the case it leaves, and the reference says so in its section on focus on arrival.
- **Tests.** A browser test submits a form inside an open shadow root by Enter in Chromium, Firefox and WebKit and finds the view the submit draws for the first time taking focus.
