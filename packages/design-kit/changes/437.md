The properties the kit declares only for its own sums are named with `--_dk-`, so a page and the
site's tokens page can tell them from tokens.

- **Tokens.** The widths a grid of buttons works its columns out with are renamed from
  `--dk-button-grid-*` to `--_dk-button-grid-*`. They were never in the reference, so no page reads
  or sets them, and the columns a grid draws are unchanged. `--dk-button-grid-columns` and
  `--dk-button-grid-least`, which a page sets, keep their names.
- **Docs.** The reference says a `--_dk-` property is the kit's own and never for a page, and
  record 16 names the convention.
- **Tests.** A test fails when the tokens sheet declares a property for a piece that the reference
  does not name and whose name does not start with `--_dk-`, or when the reference names one, and
  the tokens read from the sheet, which the site's tokens page lists, leave every `--_dk-` property
  out.
