The properties the kit declares only for its own sums are named with `--_dk-`, so a page and the
site's tokens page can tell them from tokens.

- **Sheets.** The widths a grid of buttons works its columns out with are renamed from
  `--dk-button-grid-*` to `--_dk-button-grid-*`. They came in 0.8.6 as the grid's own working
  values and were never in the reference, so a page has nothing to change, and the columns a grid
  draws are unchanged. `--dk-button-grid-columns` and `--dk-button-grid-least`, which a page sets,
  keep their names.
- **Docs.** The reference says a `--_dk-` property is the kit's own and never for a page, record 16
  names the convention, and record 2, the package README and the site's explainer give the prefix
  beside `--dk-`. The site's tokens page shows each token's value from the root rule, where a
  piece's or a picture's value for it showed before, such as `0px` for the safe area, and leaves
  `--_dk-` properties out.
- **Tests.** A rule for a piece in the tokens sheet declares only a property the reference names or
  one whose name starts with `--_dk-`, the reference names no `--_dk-` property, and the tokens read
  from the sheet, which the site's tokens page lists, hold none.
