A button or a link given the arrival focus ref keeps its place in the Tab order.

- **React.** The ref `useArrivalFocus` returns gives `tabindex="-1"` only to an element that cannot take focus by itself, such as a heading, so a button, a link or a field given it, as a scores screen's "Change round" button is, stays in the order the Tab key moves in, where before it left it for as long as the view was drawn.
- **Docs.** The hook's comment says which elements take the tabindex.
- **Tests.** A browser test gives the ref to a button, finds it with no tabindex, focuses it as its key changes, and tabs away from it and back.
