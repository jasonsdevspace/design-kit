Browser tests now prove every attach and every hook leaves nothing running once it is taken down, under the teardown contract of record 22.

- **Docs.** Record 22 names the new tests and the counters, and records 15 and 22 say the teardown tests count listeners in each engine they run in.
- **Tests.** A script loaded before each test page counts the listeners on elements, the document, the window and signals, the ResizeObservers and MutationObservers watching, and the timers and frames still to come, in Chromium, WebKit and Firefox, and in Chromium finds its count of the listeners on the window, the document and its elements equal to the engine's own. Each attach and `moveFocus` is attached, used, taken down and called after, seven times in a row, with every count back where it started each time, and each given a signal already aborted starts nothing. A page drawn by React that uses every hook is drawn, used and taken away seven times, in production and under `StrictMode`, with every count but React's own listeners on elements back where it was before. The teardown tests that counted listeners through Chromium's own tools, or timers through counters of their own, count through the same script, which in Chromium is still held to the engine's own count, and those that run in WebKit and Firefox count listeners there too.
