A toast, a dialog or a panel hands focus back from a control inside a shadow tree within it, as it
does from a plain control.

- **Controls.** The rule the toast, the dialog and the panels share for handing focus back counts
  focus inside a shadow tree within a piece or on a control slotted into it as focus in it, by
  walking out through each slot a node is drawn in and each shadow root's host, so focus on a page's
  own button component in a dialog's form, a panel or among a toast's buttons is handed back as the
  piece closes or leaves. The toast reads focus there as focus in it too, so its wait holds while
  focus is there and a message shown then keeps where focus was before. A panel reads an Escape
  where the key was pressed, inside a page's own component where the component's shadow root is
  open, so an Escape that clears a search field or closes a list there, or on a component whose host
  is marked as an open combobox, is left to the component and the panel stays open. A closed root's
  nodes are not on the event's path, so there the panel still takes the Escape. An element inside a
  component's shadow tree that shares a panel's id closes nothing, and only an open dialog or an
  open popover inside a panel keeps its Escape from the panel.
- **Docs.** The reference's sections on taking a control down, the toast, the dialog and the panel,
  and record 23, say focus inside a shadow tree within a piece counts as focus in it, and record 23
  gives the controls' new weight. The reference says a control slotted into a piece drawn inside a
  shadow root counts as in it, and its panel section says the panel reads an Escape where the key
  was pressed, inside a page's own component where the component's shadow root is open.
- **Tests.** Browser tests in Chromium, WebKit and Firefox find focus back on the opener once a
  dialog is taken down and once a panel is closed by Escape with focus on a button inside a shadow
  tree within them, and focus taken out of a toast dismissed from one where nothing on its list
  takes focus. They find a toast with no action held past its wait while focus is on such a button,
  focus sent back to where it was before the first message where a second comes while focus is
  there, focus taken out of a toast drawn inside a shadow root dismissed from a button slotted into
  it from the light DOM, and a panel left open by an Escape that clears a search field inside a
  shadow tree within it, by one in a component whose shadow tree shares the panel's id, and by one
  in a component in the panel that marks its host as an open combobox.
