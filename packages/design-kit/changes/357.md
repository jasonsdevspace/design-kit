A frame, a page that ends in a tab bar or a shown toast that carries `dk-picture` counts as a
picture, as one inside an element with the class does.

- **Sheets.** A frame, a page that ends in a tab bar or a shown toast that carries `dk-picture` is
  left out of every rule that draws a page as an app's, as one inside an element with the class is,
  so `<div class="dk-app dk-picture" inert>` leaves the page around it a content page. A pictured
  toast sits in its place, as a toast in a frame does, rather than over the foot of the screen.
- **Docs.** The reference's app frame says the class goes on the picture's wrapper or on the frame
  itself.
- **Tests.** The browser test puts the class on a frame, on a page that ends in a tab bar and on a
  lone shown toast, and holds the page around each to how it is drawn without the picture, with a
  live toast shown too. It holds the pictured toast in its place, and a page with its own frame
  beside the pictures still drawn as an app's. The scope test holds every such rule to leaving out
  an element with the class and one inside it, on every frame it names.
