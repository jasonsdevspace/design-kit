A panel drawn beside its button inside an open shadow root opens, closes and hands focus back
there.

- **Controls.** `attachPanel` looks for a button's panel by its id from the button's own root out
  through each host to the document, as a focus request finds an id, and keeps each panel's state by
  the root that holds it, so a widget's panel and the page's with the same id stay apart. The press,
  Escape and the corner Close are read inside an open shadow root, and where no button takes focus as
  the panel closes, focus goes on past the widget to the page's next control.
- **Docs.** The reference says where a panel is looked for from its button, and that a button inside
  a closed shadow root opens nothing.
- **Tests.** The focus grid's panel squares for an open shadow root and one inside a frame pass.
  Browser tests open and close a widget's own panel by its Close and by Escape apart from the page's
  panel with its id, hand focus on past the widget, start a panel as a button drawn again says once
  the one before it left, and close by Escape a page's panel a widget's button opened before the
  page drew it.
