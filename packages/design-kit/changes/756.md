The React hooks read where focus was inside a closed shadow root through an element they hold.

- **React.** `useFocusAfterDraw` reads where focus was through its target where that is an element, `useFormRefusal` through the newest form it refuses for and `useArrivalFocus` through its heading, so inside a closed shadow root a visitor who moves to another control there before a request lands is left there, as in an open one.
- **Docs.** The reference's section on where focus can be says the hooks read a move inside a closed root as the visitor's.
- **Tests.** A browser test moves focus to another control inside a closed shadow root before a `useFocusAfterDraw` request there lands and finds focus left there in Chromium, Firefox and WebKit.
