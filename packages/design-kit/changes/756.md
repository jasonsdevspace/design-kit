The React hooks read where focus was inside a closed shadow root through an element they hold.

- **React.** `useFocusAfterDraw` reads where focus was through its target where that is an element, `useFormRefusal` through the form a refusal is for, the newest for the page's own and each form for its own failed submit, and `useArrivalFocus` through its heading once it is drawn, so inside a closed shadow root a visitor who moves to another control there before a request lands is left there.
- **Docs.** The reference's section on where focus can be says what each hook reads where focus was through inside a closed root, and that a view's first draw reads it as the host.
- **Tests.** Browser tests land a `useFocusAfterDraw` request inside a closed shadow root and focus a `useArrivalFocus` heading there as its key changes, and find focus left where it moved there before either lands, in Chromium, Firefox and WebKit.
