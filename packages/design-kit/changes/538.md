The status line's release stays inside the kit rather than becoming a second public way to take a piece down.

- **Controls.** The state of each status line and the release `StatusProvider` uses live in a module of the kit's own, which the package's exports do not name, so `./controls` publishes no release function beside the detach its attach functions return.
- **Tests.** The browser tests' pages serve the new module beside the controls, and the type smoke test and the list of exports no longer name a release function.
