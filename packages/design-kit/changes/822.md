A panel's root is settled as its button is attached, and the code that hears a closed shadow root
loads only with a piece that reads focus.

- **Upgrading.** A panel the page draws after attaching its button, in a root other than the one its
  panel was found in as the button was attached, or the button's own where none was, is no longer
  found, so a page attaches the button once its panel is drawn.
- **Controls.** `attachPanel` finds a button's panel root once, as the button is attached, and keeps
  it, so no read moves a panel's state between roots. The code that hears a closed shadow root moves
  out of the module every page that imports the controls loads, into the one a piece that reads
  focus loads, so the module imported bare and `attachTable` alone are smaller. The search for a
  frame across another origin keeps the frame it finds, a key press is checked once, and an input is
  kept for a closed root's listener only once one is heard.
- **Docs.** Record 19 and the reference's panel section name a panel drawn later in another root as
  out of reach. Record 13 says why the module imported bare grew in this release, and the budgets
  are set again by its rule.
- **Tests.** Browser tests give a checkbox field a line of its own in a row of fields, draw a
  refused box's error right before its label, order views brought by one press through a frame of
  the page's origin, refuse each of two forms in a closed shadow root for its own submit alone, read
  focus in a frame of the page's origin inside one of another origin as that frame while the
  browser's window has no focus, and stop the panel's walk at a closed details' summary. A unit test
  draws a read-only box that is off in the words given, the checkbox field's markup is checked by
  its parts rather than a copy of the whole, and the panel walk's cost is counted by its own
  selector against a tight bound. Two browser tests of a panel drawn after its button in another
  root are gone, and one of a closed root's panel is left to the focus grid, which checks where
  focus lands too.
