A toast, a dialog or a panel hands focus back to any element that takes it, a link inside an inline
SVG among them.

- **Controls.** The handback the toast, the dialog and the panels share focuses an SVG element as it
  does an HTML one, so focus that came into a toast from a link in an inline chart goes back there,
  a dialog opened from one returns focus to it, and a closing panel can hand focus to one that
  follows it. A dialog's `returnTo` may give any element.
- **Docs.** The reference's section on taking a control down and record 23 say a handback can land
  on any element that takes focus, and record 23 gives the controls' new weight. Record 19 says the
  panel spec runs in Firefox too.
- **Tests.** Browser tests in Chromium, WebKit and Firefox find focus back on a link inside an
  inline SVG after a toast is dismissed by Escape on its Close and after a dialog it opened closes,
  and sent to one after a panel with no button left. The dialog and panel specs run in Firefox too.
